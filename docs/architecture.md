# Semantics and pipeline

The core is implemented in this repository. Utility crates provide serialization, hashing and bounded task scheduling, not a decompiler. Its semantic references are pinned official Luau instruction definitions, compiler lowering/validation, loader and VM execution. The older source is [0.654](https://github.com/luau-lang/luau/tree/8cc289fae430d9b0c22bde209fe5cf2d01751ff1); additional pinned revisions and compiler checksums are in [upstream.profiles.lock.json](../upstream.profiles.lock.json). See [compatibility](compatibility.md) for the exact version matrix.

## Analysis and reconstruction

1. **Profile and validated decoding.** profiles.rs selects an explicit format contract. Bytecode decoding checks canonical varints, sizes, type encodings, flags, constants, register/prototype/string references, instruction widths, branches, capture ownership and supported open-result sequences. Type metadata retains raw bytes, tags, source offsets, local PC lifetimes and userdata names. Format-specific handling includes prefilled table constants, userdata encodings, feedback slots and exact prototype boundaries. Unsupported tags/operations fail; unknown fields are not silently skipped. Explicit opcode normalization changes instruction header bytes while preserving AUX words. Serialized PCs remain word offsets.
2. **Control flow.** cfg.rs creates basic blocks, predecessors/successors, reachability, immediate dominators and back edges. It avoids a quadratic dominance matrix. The invocation edge into block zero remains distinct from a loop entering that block.
3. **Data flow.** dataflow.rs computes definite initialization, liveness, SSA definitions/phis and packed reaching-value lookups. A may-open reference-capture analysis records when register writes can be observed through a closure; a later capture does not taint unrelated earlier scratch use. Register sets use four machine words. Fixed points, block/register products and packed read/definition counts are bounded.
4. **Binding recovery.** bindings.rs joins live phi inputs and assignments covered by debug-name PC intervals, including the reaching initializer before an interval begins. Independent later register reuse gets a separate identity where proven. Captured and native-loop storage remains conservative. Names and overrides are applied after this recovery, with globals and injected constructor roots reserved.
5. **Source construction.** structure.rs lifts effects and value lists into ast.rs. It recognizes native branches and loops when their hidden VM state is unobserved, reconstructs closure contexts, and traces literals/builtin origins through SSA and agreeing joins. Unsupported evidence stops reconstruction. A complete dispatcher handles supported CFGs which do not fit structured regions.
6. **Readability and output.** Temporary propagation follows adjacent safe evaluation points and liveness. Native captured writes are explicitly observable and cannot disappear into a later expression. Declarations go in the smallest existing structured scope containing their uses. Large blocks also receive bounded do-scopes around proven finite local lifetimes, preserving outside references and allowing compiler slot reuse. format.rs enforces syntax depth, precedence, scalar expansion, output limits and Luau's local/upvalue limits.
7. **Types and presentation.** types.rs associates metadata and bounded AST assignment/call/return/capture constraints with recovered bindings, rather than permanent register names. type_ast.rs represents annotations, optional/union/intersection types, records/arrays/dictionaries, callbacks, generic functions/packs and aliases. Signatures and inheritance come from the pinned full Roblox API declarations; explicit project/binding contracts are marked external. Unknown constraints stay unknown. The typed printer emits annotations, safe local functions, multiline tables/calls and source maps without adding runtime assertions or conversions.
8. **Independent quality and finite recovery.** quality.rs sends final formatted source over LQUAL/1 to a persistent bounded official Luau parser/compiler/analyzer worker. Virtual module resolution and project contracts are explicit; dependency/runtime code is not executed. Compile-time user type functions are rejected. Independent syntax/compilation/strict results, unresolved dependencies, assumptions, `any`, assertions and tool/context hashes remain separate from instruction coverage and behavioral tests. Recovery attempts annotated, metadata-only and faithful-baseline candidates within shared deadline/cancellation/work/memory constraints. Diagnostics identify generated nodes and only bytecode intervals supported by evidence.

Independent prototype analyses are memoized once per input. At least 16 prototypes may share an existing explicit bounded Rayon pool. Closure expansion, helper allocation and naming remain ordered. The implementation does not initialize an unbounded global worker pool.

## Closures, expressions and tables

Native lexical reference captures are emitted only when register lifetime and transitive capture uses establish a safe representation. A nonterminal CLOSEUPVALS or a transitive DUPCLOSURE pointer-identity dependency keeps the conservative cell representation. Cells preserve old closure lifetimes when VM registers are reused; CLOSEUPVALS creates the subsequent independent cell lifetime.

NEWCLOSURE and DUPCLOSURE have different allocation/sharing behavior. NEWCLOSURE capture preinitialization requires absence of a self-value capture and an explicit closure-allocation identity proof. Acyclic single-entry root sites can use ordinary function declarations; repeatedly evaluated sites retain a private identity guard unless fresh allocation is otherwise established. Open-result scratch proof checks active reference captures at both producer and consumer, retaining liveness checks. Pending open-result sequences cannot introduce an unchecked CAPTURE; closing a capture later does not make an earlier overwrite safe. Private readiness guards can force a fresh source closure. DUPCLOSURE reconstruction preserves the cached first capture tuple where required; comparisons use raw identity rather than user __eq behavior. A proven acyclic, single-use main site can use a direct literal. Entry-local caches cannot universally preserve repeated invocation of one loaded entry. `closure_scope` records those restrictions. `closures.entry_invocation = repeated` rejects unsupported sharing and requires an explicit target-compiler sharing contract for the supported zero-upvalue strategy; it does not certify arbitrary optimizing compiler behavior.

Calls and varargs retain scalar versus expanding value-list contexts. Continuations preserve ordering when a pending multiple-return expression would otherwise run after a prefix or method lookup. NAMECALL uses colon syntax when representable, including tested __namecall behavior. Arithmetic, comparison, indexing, concatenation and assignments retain native operators so metamethod dispatch remains observable.

Table reconstruction preserves the relevant array/hash allocation hints rather than replacing every table with an empty constructor. Nil-filled array fields preserve holed-array borders. Hash reservations use a proven first key. For a dynamic first key, allocation can be delayed until the unique first store only after proving the receiver unescaped and untouched; key/value effects still happen first. Fixed SETLIST may span dominating, nonescaping paths. Cross-block open SETLIST requires one dominating fresh array-only constructor with no prior writes, escape or alias; conditional insertion histories remain explicit rejections.

Prefilled table templates preserve loader insertion order, numeric-zero placeholders and deferred nil resets for supported string keys. Vectors require an explicit trusted immutable constructor contract; no Roblox spelling is guessed. Direct getfenv references are accepted only when all proved uses are getfenv(0) calls, avoiding stack-depth-sensitive introspection.

## Complete CFG fallback

Auto mode retries only recognized structured-region shape failures, restoring naming/helper/cache state before the retry. The fallback builds a balanced decision tree inside a private state loop. Every reachable basic block executes its real lowered operations in order and assigns its exact successor state. Persistent VM values are declared outside the artificial loop.

Coverage is checked after either path. No reachable instruction can be omitted or replaced with nil, a placeholder call, a comment or an instruction listing presented as source. Dispatcher output sets quality to dispatcher and lists affected prototypes. Proven single-entry numeric/generic for regions can be collapsed into native loops within the dispatcher; other VM FOR arrangements reject. Cross-block open results still require their separate producer/insertion proof.

FASTPCALL is lowered only after proving the version-specific protected builtin ID, fallback GETIMPORT/CALL layout, argument arrangement and guard target. Ordinary source protected calls preserve the tested success/error/yield/return behavior. Target-opcode occurrence and runtime fastpath eligibility are measured separately, so enabling a format or compiler flag cannot substitute for instruction-feature evidence.

## Bounded execution

Limits apply before repeated string/name expansion, prototype DAG expansion and large allocations. Aggregate function estimates divide one analysis allowance across tasks. Dense live-name optimizer work and scope-lifetime work are separately checked; short bytecode cannot request unlimited AST duplication. Final lexical limits remain enforced after declarations are placed, rather than incorrectly counting pending SSA locals as free upvalues.

A persistent service CPU pool exposes intra-script parallel analysis to executor requests. Execution contexts propagate cancellation/deadlines/work through function tasks and analysis loops. Streaming batches retain bounded ordered windows. Service admission stages input, decoded/validated structure, analysis and controlled source/JSON growth, then retains response/cache leases through send/disposal. A separate bounded writer pool prevents slow sockets from occupying CPU workers. Persistent analyzers have bounded worker/cache admission, finite frontend limits and cancellation/timeout disposal. These weighted reservations are not a hard RSS/heap quota; measurements report actual memory separately.

## Equivalence boundary

The default target is ordinary execution of one loaded script-entry invocation within the explicitly supported environment. Repeated-entry requirements are separately configured/reported and reject unproved closure sharing. Source reconstruction cannot restore erased spelling, original lexical blocks, source locations, stack shape, debug-local inspection, allocation counts, GC timing, native dispatch or coverage state. Error location prefixes and stack traces can therefore differ; the typed oracle does not normalize them away. Hostile environment mutation and introspection through arbitrary aliases need separate proof.

A successful complete result states that the accepted lowering covered every reachable instruction. It does not establish all-input equivalence by itself. The [typed validation](validation.md), [oracle protocol](oracle.md), measured [compatibility matrix](compatibility.md) and [remaining limits](validation.md#remaining-limits) define the evidence actually available.

## Native and browser boundaries

`platform` supplies native monotonic time or browser performance time. `parallel` preserves Rayon pools natively and provides a deterministic one-worker sequential implementation for WASM. Filesystem assets, subprocess validation, native scheduling and HTTP listeners remain native-only. The WASM library exports direct byte/source processing and typed JSON results; a worker invokes the same quality/recovery logic through an in-memory request frame to the Emscripten-built pinned analyzer. The C++ implementation shares its parser/compiler/analysis body across native and WASM builds.

Attribution finalization is a shared Rust stage. It runs on every public source candidate before output positions, final validation and hashes are observed; raw input identity remains distinct. Browser clipboard/downloads use the same finalized result bytes. Worker supervision supplies hard cancellation/recreation when synchronous WASM cannot observe messages, while native cooperative cancellation and persistent pools retain their existing behavior. Static asset manifests bind engine, C++, definitions and schema versions.

# Luau Decompiler

A standalone Rust decompiler and source processor for readable, meaningfully typed Luau, with an entirely browser-local application.

[Open the browser app](https://zionqyl.github.io/luau-decompiler/) | [MM2 showcase](examples/Murder%20Mystery%202) | [Whole-module example](examples/typed-output/module_organization.luau)

## Status and scope

`0.4.0-rc.5` is a release candidate. See the [current assessment](docs/release-candidate.md) for exact validation and publication identities. Supported inputs are explicit Luau bytecode profiles 3-14, the evidenced Roblox signed container, and documented source subsets. Standard Lua/LuaJIT bytecode is rejected. Missing contracts, unsupported operations and failed typing remain visible.

## Install on Windows

Install the latest published preview per user, with verified prebuilt assets and no contributor toolchain:

```powershell
& ([scriptblock]::Create((Invoke-RestMethod https://raw.githubusercontent.com/zionqyl/luau-decompiler/main/scripts/install.ps1))) -Repository zionqyl/luau-decompiler -Preview
```

[Installation, pinned versions and offline ZIP use](docs/installation.md). Installed local processing needs no account, Roblox, executor or server.

## First conversion

```powershell
& "$env:LOCALAPPDATA\LuauDecompiler\luau-decompile.cmd" decompile input.bc --policy verified-typed -o output.luau --quality-report quality.json
```

Verified typed output requires final-source parsing, compilation, strict analysis and meaningful typing. Failed quality retains recoverable source with a failing status. This [bytecode-derived output](examples/typed-output/verified_bytecode.luau) was generated by the engine:

```luau
--!strict
--[=[
    Luau Decompiler 0.4.0-rc.5
    Made by @zionqyl
    https://github.com/zionqyl/luau-decompiler
]=]

local function add(value: number): number
    return value + 2
end

local answer: number = add(40)

return answer
```

# Luau Decompiler

A standalone Rust decompiler and source processor for readable, meaningfully typed Luau, with an entirely browser-local application.

[Open the browser app](https://zionqyl.github.io/luau-decompiler/) — processing and strict validation run locally on your device.

## Status

`0.4.0-rc.4` is a [published release candidate](https://github.com/zionqyl/luau-decompiler/releases/tag/v0.4.0-rc.4). Windows x64 runtime/installer and Ubuntu 24.04 x64 runtime/container checks passed clean CI; the public Windows installation and anonymous container pull were verified. The static browser application uses the shared Rust WASM engine and pinned Luau compiler/strict analyzer in workers. [Browser status](docs/browser.md) / [platform evidence](docs/hosting.md#evidence-boundary-for-this-candidate).

Supported inputs are explicit Luau bytecode profiles 3 through 14, the evidenced Roblox signed-container profile, and documented source subsets. Standard Lua/LuaJIT bytecode is recognized and rejected. Missing contracts and unsupported operations remain visible; strict success is separate from behavioral correctness.

## Install on Windows

Install the verified prebuilt runtime per user. No contributor toolchain is required. [Installation and offline ZIP usage](docs/installation.md).

```powershell
& ([scriptblock]::Create((Invoke-RestMethod https://raw.githubusercontent.com/zionqyl/luau-decompiler/v0.4.0-rc.4/scripts/install.ps1))) -Repository zionqyl/luau-decompiler -Version 0.4.0-rc.4 -Preview
```

No developer tools, account, Roblox, executor or server are needed for installed offline processing.

## First conversion

```powershell
& "$env:LOCALAPPDATA\LuauDecompiler\luau-decompile.cmd" decompile input.bc --policy verified-typed -o output.luau --quality-report quality.json
```

Verified typed output must pass final-source parser, compiler, strict analysis and meaningful-typing gates. Failed quality retains recoverable source and diagnostics with an unsuccessful status. This real bytecode-derived [output](examples/typed-output/verified_bytecode.luau) is generated by the engine:

```luau
--!strict
--[=[
    Luau Decompiler 0.4.0-rc.4
    Made by @zionqyl
    https://github.com/zionqyl/luau-decompiler
]=]

local function add(value: number): number
    return value + 2
end

local answer: number = add(40)

return answer
```

## Limits and license

Support is per program. Erased types and unknown external contracts cannot be recovered by assumption. Linux evidence covers its recorded CI environment; HTTPS, distinct-image upgrades, macOS and mobile remain untested. See the [support matrix](docs/support-matrix-rc.md), [limitations](docs/remaining-limitations-rc.md) and [candidate assessment](docs/release-candidate.md).

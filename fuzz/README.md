This target fuzzes the decoder and, on valid inputs, the reconstruction pipeline.
Its allocation and analysis limits are deliberately smaller than production
defaults. No bytecode or resulting source is executed.

On a host supported by cargo-fuzz (Linux recommended), install Rust nightly and
`cargo-fuzz`, then run from the repository root:

```sh
mkdir -p fuzz/corpus/bytecode
cp tests/fixtures/*.bc fuzz/corpus/bytecode/
cargo +nightly fuzz run bytecode -- -max_len=65536 -rss_limit_mb=512 -timeout=5
```

The checked-in corpus is generated by `scripts/generate-fixtures.ps1` using the
official compiler pinned in `API.md`. A fuzz target's presence is not a claim of
a completed fuzz campaign. Ordinary `cargo test` also runs deterministic byte
mutations and every truncation of the compiler-generated fixtures.
